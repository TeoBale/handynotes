# HandyNotes

This app is a small tool for taking notes
quickly and conveniently in a window that’s always at your fingertips.
We offer a service for syncing and saving notes online, but
this is entirely optional; the app (which is the focus of the project)
can still be used offline and privately.

## UI SDK

Before using UI SDK, follow the `ui-sdk` skill if it is installed. From
`web/`, read `node_modules/@ui-sdk/react/docs/llms.txt`.

When building a new component, also search the headings in
`node_modules/@ui-sdk/react/docs/core.md` and read `rendering.md` in the same directory.
